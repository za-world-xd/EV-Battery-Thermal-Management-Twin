# EV-CellTwin

Educational electro-thermal cell and homogeneous pack simulator.
Parameters are illustrative and require experimental calibration.

## Available workflows

Current interface: Streamlit workbench with baseline comparison and complete-node CSV export.

## Included components

- Implement coupled cell physics and drive-load kernel.
- Expose simulation and flow comparison through FastAPI.
- Add thermal workbench and baseline comparisons.
